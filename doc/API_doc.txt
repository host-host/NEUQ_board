POST /api/gpts2
请求值：无
返回示例：
[{"provider":"deepseek","public":["deepseek-v4-flash"],"private":["deepseek-v4-pro"],"format":"completions"}]
解释：
provider表示模型提供商
public表示可以访问的模型
private表示需要权限访问的模型
format表示上游格式，默认是completions。


POST /api/gpt5_model_list
鉴权：无
请求值：无
返回值：gpt3.json 去掉 title；provider 的每一项去掉 name、url 和 Authorization，只保留 format、public 和 multiply。
返回示例：{"model_multiply":{"gpt-5.6-sol":[35,210,3.5]},"model_available_provider":{"gpt-5.6-sol":["B","C"]},"provider":{"B":{"multiply":0.0114,"format":"responses"},"C":{"multiply":0.0171,"format":"responses","public":true}}}
解释：model_available_provider 按顺序列出每个模型可以选择的 Provider；没有保存有效选择时使用第一个有权限且格式匹配的 Provider。

POST /api/gpt5_apikey
鉴权：Cookie 登录
请求示例1：{}
请求示例2：{"rotate":true}
请求示例3：{"model":"gpt-5.6-sol","provider":"C"}
返回值：JSON 对象，api_key 为当前用户的 API 密钥；token_limit 和 token_used 分别为总额度与已用 token 数；admin 表示管理员权限；selected_provider 表示当前有效的 Provider 选择。
返回示例：{"api_key":"sk-12345678abcdefghijklmnopqrs","token_limit":10000000,"token_used":1234,"admin":false,"selected_provider":{"gpt-5.6-sol":"C"}}
解释：无密钥时初始化密钥；rotate 为 true 时轮换并立即废止旧密钥。
计费：token_used 增加 ceil(used_tokens * model_multiply[model][0] * 0.5 * provider[provider].multiply / 0.3)。


POST /api/gpt5_resolve
请求示例：{"response_id":"resp_xxx"}
返回示例：{"con_id":"12345"}
解释：根据上游 response.id 查询本地历史会话 ID。


POST /api/gpt5_history_list
鉴权：Cookie 登录
返回值：当前用户未删除的历史对话元数据数组，每项包含 con_id 和 name。
返回示例：[{"con_id":"12345","name":"New title"},{"con_id":"67890","name":""}]
解释：name 为空表示标题尚未生成；完整对话内容需通过 /api/gpt5_history_get 按需读取。


POST /api/gpt5_history_get
鉴权：私有会话需要 Cookie 登录且仅所有者可读；已分享会话允许匿名读取
请求示例：{"con_id":"12345"}
返回值：content 结构体


POST /api/gpt5_history_rename
鉴权：Cookie 登录
请求示例：{"con_id":"12345","title":"New title"}
返回示例：{"ok":true}
解释：仅会话所有者可重命名；


POST /api/gpt5_history_delete
鉴权：Cookie 登录
请求示例：{"con_id":"12345"}
返回示例：{"ok":true}
解释：软删除，设置 content.deleted 并从用户历史列表移除。


POST /api/gpt5_share
鉴权：Cookie 登录
请求示例：{"con_id":"12345","publish":true}
返回示例：{"ok":true}
解释：仅会话所有者可分享，publish 目前只能为 true；分享后可通过 /api/gpt5_history_get 匿名读取。
